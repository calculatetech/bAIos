## Implementation and decisions


Use four Boot slots with Disabled=0, Floppy=1, Hard Disk=2, CD-ROM=3 and Other=4. Defaults are Floppy, Hard Disk, Disabled, Disabled. Selecting an allocated non-disabled target moves it and shifts intervening slots. Saved duplicates remain invalid. Schema5 packs first/theme in CMOS3C, second/fourth in3E and third in3F. Preserve original schema1-4 meanings and default the fourth slot to Disabled. Other invokes the captured option-ROM INT19 chain at its selected priority.

Use a small transient record in free EBDA space, following the BDA pointer on each public call. Poll ATAPI with bounded PIT waits, check interrupt reason and device byte count, handle media readiness using REQUEST SENSE, and restore the existing IRQ policy on every exit. Transfer requested portions directly from the 2048-byte CD block; discard other words. Do not reserve a persistent CD buffer.

Validate the Boot Record descriptor and catalog checksum/platform/key/default record. Honor load segment and 512-byte load count, without requiring a floppy signature for no-emulation images. Use capacity and conventional-memory bounds to reject invalid loads, including the live boot stack below7C00h. Install a relocatable INT13 wrapper after option ROM initialization, preserving its predecessor. No-emulation uses drive E0h and 2048-byte EDD sectors. Emulated images provide read-only 512-byte CHS services and geometry; displaced real A forwards as B and the physical B is inaccessible until termination. AH4B returns the standard packet and can terminate emulation. INT18, INT19, next target and retry clear active CD state and restore counts. Optional AH4A/4C re-initiation and multi-image AH4D selection are not claimed; reject unsupported functions.
