# Presario 800: Cirrus VGA BIOS 1.41 and validated bus07

This report records the original Compaq 1.30 versus unmodified Cirrus 1.41 comparison. The optional `-Vga141` build still uses the supplied VGA bytes and retained OEM resources. The main build now uses the approved RAM profiles and bus07 VGA, with separate 50 MHz and 60 MHz releases. See [current build and validation commands](../README.md#build-and-test).

## Validated physical reference

The user accepted bus07 on the Presario 800 with a DX2-66, a 33 MHz VLB bus, and 1 MiB of soldered HM514270AJ7 memory. The exact 128 KiB image is versioned at `presario-800/reference/baios-presario800-vga141-bus07.bin`. Its SHA-256 is `98716A7CEFC742047806C70A8CBEA04A89648C5BF84859FA1CEA269D791633B7`.

```powershell
python -B presario-800/tools/build-vga-bus.py
```

This command reproduces that reference under `presario-800/build/vga141/bus07/`. It uses the original VGA input and the frozen reference system/resources. It does not incorporate later system BIOS changes or recreate older experiments. Keep new RAM candidates separate from this reference.

Bus07 changes only VGA offsets `08E6h`, `08E7h`, `08E8h`, and the checksum byte `7FFFh`. It selects SR16 `48h` (one-clock I/O, two-clock writes, FIFO threshold 8), SR1F `22h` (nominal 60.852 MHz), and local DAC completion through SR17 bit 0. Mode changes retain these controls. The memory clock exceeds the GD5428 specification. Physical acceptance applies to this tested board.

Physical readback was SR0F `15h`, SR16 `48h`, SR17 `30h`, SR1F `22h`, and SR07 `00h`. This confirms the VLB strap at or below 33 MHz. Text mode became faster. Doom realtics did not improve as the memory clock increased from 50 to 60 MHz. A run of the user's exact Doom executable also confirmed that SR1F and SR16 persisted in its graphics mode.

Obsolete tuning outputs and previous main images are purged. Git retains their source history. Bus04's FIFO threshold 6 was rejected after slower Doom results. The original ROM inputs and current comparison results remain available.

## Untuned comparison build

From the repository root, run:

```powershell
powershell -NoProfile -File presario-800/tools/build.ps1 -Vga141
powershell -NoProfile -File presario-800/tools/verify-rom.ps1 -Vga141 -SelfTest
```

The physical candidate is `presario-800/build/vga141/baios-presario800-vga141.bin`, 131072 bytes. Its system ROM remains 65536 bytes with a zero byte-sum checksum. The variant has a private emulator ROM tree and VM. An optional build cannot use the main build directory.

The original `test-vga141.py` comparison assumes the earlier OEM main build. Its retained results below describe that historical comparison. Use the current release validation commands linked above for the promoted main ROM.

The system BIOS selects the matching VGA header and public INT10 handler. The addresses are C000:27B7 for 1.30 and C000:2897 for 1.41. Startup seeds INT42 at the matching handler plus one. Both VGA installers still replace INT42 with F000:F065, so the system bridge remains at that fixed address. No RAM, cache, chipset, or video timing adjustment accompanies this adaptation.

## Register comparison

Both ROMs run on the same D824 model with exactly 1 MiB of video memory. The guest checks the reported capacity and independent storage at 0, 512 KiB, and the final 4 KiB bank. The D824 model uses an ISA GD5428. Its bus straps do not establish the physical board's bus timing. The [86Box device source](https://github.com/86Box/86Box/blob/master/src/machine/machine_table.c) identifies that model.

The guest records 159 register readbacks at each of 14 checkpoints. It includes sequencer, CRTC, graphics, attribute, miscellaneous-output, and hidden DAC controls. The first checkpoint follows POST text restoration. These are final states, not a trace of transient initialization writes. Undefined register effects and physical performance remain unmeasured.

| Control | Compaq 1.30 | Cirrus 1.41 | Meaning |
| --- | --- | --- | --- |
| SR0F, text/planar | 10h | 10h | Same 32-bit DRAM width, eight-level display FIFO, RAS and clock strap readback |
| SR0F, packed pixels | 30h | 30h | Same 16-level display FIFO |
| SR16 | D8h | D8h | Same FIFO threshold 8 and local-bus delay fields |
| SR17 | 39h | 39h | Same emulator ISA configuration readback |
| SR1F | 1Ch | 1Ch | Same nominal memory clock: 50.114 MHz |
| CR11 bit 5 | 1 | 0 | 1.30 disables vertical interrupts; 1.41 enables them |
| GR06, VBE 0111h | 07h | 05h | 1.41 clears the odd/even plane-chain flag in 640×480×16 mode |

CR11 differs by 20h in every checkpoint. Its sync-end field and refresh-cycle bit remain equal. The interrupt-enable change does not alter raster timing. The effect of the chip's interrupt output on the physical board still needs observation. All other recorded controls match, except GR06 in VBE 0111h.

The [Cirrus January 1994 technical reference](https://bitsavers.trailing-edge.com/components/cirrusLogic/graphics/CL-GD542X_Technical_Reference_Manual_Jan1994.pdf) defines CR11 in section 6.19, GR06 in 7.8, SR0F in 9.6, SR16 in 9.12, and SR1F in 9.18. SR16's upper delay fields apply to local-bus configurations. Equal ISA-model readbacks do not prove equal local-bus performance.

## Clock and display timing comparison

Both ROMs produce the same values in this table. Clock figures assume the nominal 14.31818 MHz reference. VCLK is the synthesizer output. Packed 16-bit and 24-bit modes use output division, shown separately. Horizontal totals are in dot-clock periods. Interlaced vertical totals describe the programmed field timing.

| Checkpoint | VCLK MHz | Pixel division | Horizontal total | Vertical total | Interlaced |
| --- | ---: | ---: | ---: | ---: | --- |
| POST / mode 03h / 80x50 / restored 80x25 | 28.325 | 1 | 900 | 449 | No |
| VGA 640×480×4 / VBE 0101h | 25.227 | 1 | 800 | 525 | No |
| VGA 320×200×8 | 25.227 | 1 | 800 | 449 | No |
| VBE 0102h / 0103h, 800×600 | 36.082 | 1 | 1024 | 625 | No |
| VBE 0104h / 0105h, 1024×768 | 45.076 | 1 | 1264 | 408 | Yes |
| VBE 0106h, 1280×1024×4 | 75.000 | 1 | 1552 | 556 | Yes |
| VBE 0111h, 640×480×16 | 49.867 | 2 | 800 | 525 | No |
| VBE 0112h, 640×480×24 | 75.496 | 3 | 800 | 525 | No |

The clock calculation uses the selected SR0B..0E numerator and SR1B..1E denominator/post-divider pair. The [86Box Cirrus implementation](https://github.com/86Box/86Box/blob/master/src/video/vid_cl54xx.c) supplies the model's pixel-format divisions. Memory clock equals `reference × (SR1F & 3Fh) / 8`.

Raw untuned snapshots and the complete register comparison are generated under `presario-800/build/vga141/`: `registers-oem.json`, `registers-141.json`, and `register-comparison.json`. The emulator checks actual VGA pixels, native/VBE banking, retrace, pending IRQ delivery, Setup/summary text restoration, and graphics-to-Ctrl+Alt+Del warm entry. Native Setup and summary captures are under `build/vga141/chipset-review`. These comparisons describe the original inputs before bus07 tuning.
