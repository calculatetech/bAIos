# PB430 v0.1.0

Two complete 128 KiB programmer images are provided for the Packard Bell PB430:

| Image | VGA clock | Size | Programmer SUM32 |
| --- | --- | --- | --- |
| `baios-pb430-v0.1.0-vga50.bin` | 50 MHz | 131,072 bytes | `0123BF00` |
| `baios-pb430-v0.1.0-vga60.bin` | 60 MHz | 131,072 bytes | `0123BF00` |

Use the 50 MHz image for the lower VGA clock. The 60 MHz image retains the VGA clock used during PB430 development and performance testing. Both contain the same system BIOS, Setup settings, and defaults. Floppy Controller is configured on the Drives page.

These are full physical ROM images, ready for an external programmer. Keep your original ROM and use the image for the matching board. The release does not flash the board automatically.

SUM32 is the additive sum of all bytes in the full image. The checksums are equal because the VGA checksum adjustment compensates for the clock-byte change. Use the filename to select the clock variant.

## Validation

Both images pass size, reset target, VGA header/checksum, system checksum, and retained-region checks. They differ only at VGA offsets 0x08E7 and 0x7FFF. The 64 KiB system BIOS is byte-identical. These exact release files have not received a new physical-hardware test; the 50 MHz selection uses the established Presario build recipe.

## Reproduction

Supply the private inputs listed in `docs/private-inputs.json`, then run:

```powershell
python -B pb430/tools/build.py --vga60
```

This produces `pb430/build/vga60/baios-pb430.bin`. Copy it under the release's 60 MHz filename. To produce the 50 MHz image, use the same adjustment as `presario-800/tools/build.ps1`: set byte 0x08E7 to 0x1C, then set byte 0x7FFF to the negative sum of bytes 0 through 0x7FFE, modulo 256. Leave every other byte unchanged. The 60 MHz clock byte is 0x22.
