# PB430 firmware port

## Outcome

Compose a complete PB430 port from the existing modular firmware. Preserve the Presario-800 POST, setup, interrupt services, device discovery and boot behavior. Replace hardware owners with ACC2168 and ACC3221 code supported by the supplied PB430 ROM, the ACC2168 manual and the ACC3221 data sheet. ## Decisions and source limits

Preserve raw chipset values when bit meanings are unknown. Do not invent timing profiles, memory capacities or controller capabilities. POST Write is OEM-only and requires four 245 transceivers, so do not expose it without board evidence. CAS bits are documented but their 2T/3T encodings are not established; keep the OEM encoding until independent evidence supplies the mapping. ACC3221 provides compatible/bidirectional parallel modes, not M919 EPP/ECP.

The supplied Phoenix RAM table lookup overwrites its search flags at 9BA6. Mode 0 takes its fallback path; unmatched mode 1 takes a last table entry. Do not silently copy or silently repair that behavior. Validate known mode-1 matches against raw table bytes, emit an explicit diagnostic for unsupported topology, and prove physical memory with the stock alias-aware count rather than assigning KiB from a probe code. Normal cold table 05=18 selects mode 1. Document any retained support limit.

The cache probe and display contain separate ambiguous last-candidate behavior. Presence and size are different facts. Do not claim installed cache merely because a control bit is writable, and do not label an ambiguous result as a proven size. Retain observed enable/disable choreography and distinguish emulator behavior from physical SRAM qualification.

Reserve at least 8 KiB EBDA because the shared RAM backup occupies 1800-1FFF. Keep the vectors at F000. Verify the PB430's RTC/A20/keyboard contracts through source and native fixtures before retaining the existing extended CMOS and A20 owners.
